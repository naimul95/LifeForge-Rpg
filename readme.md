# ⚡ LifeForge RPG

> **A Personal Life Operating System that turns real-life goals, habits, learning, and daily activities into an RPG-style experience.**

LifeForge RPG is a full-stack personal productivity and self-development platform designed to help users **learn, build habits, complete goals, track progress, and improve their daily life** through an engaging RPG-inspired system.

Instead of using separate applications for studying, goals, habits, productivity, and personal progress, LifeForge brings them together into one unified **Personal Life OS**.

---

## 🎯 Main Focus of LifeForge RPG

The main goal of LifeForge RPG is:

**"Turn real-life progress into a game-like journey."**

Users can:

- 🎯 Create and track long-term Goals
- 🔁 Build and monitor Good/Bad Habits
- 📚 Organize learning materials in the Learning Vault
- ⏱️ Track study time with Study Timer
- ⚡ Complete Missions and earn XP
- 🏆 Unlock Achievements
- 📊 Analyze personal progress
- 🗺️ View their Life Journey
- 🧠 Take short Mind Refresh games
- 🔔 Manage reminders
- 👤 Manage their profile and preferences

The application combines **productivity + learning + self-improvement + gamification** into one platform.

---

# 🧠 Why LifeForge RPG?

Traditional productivity applications usually focus on only one area.

For example:

- A study application focuses on studying
- A habit tracker focuses on habits
- A task manager focuses on tasks
- A goal tracker focuses on goals

LifeForge RPG connects these areas.

### Example

A user wants to become better at programming.

They can:

1. Create a **Goal**
   - "Become a Full-Stack Developer"

2. Create **Roadmap items**
   - HTML
   - CSS
   - JavaScript
   - React
   - Next.js

3. Store learning resources inside **Learning Vault**

4. Use **Study Timer** to track learning time

5. Create a **Good Habit**
   - "Code for 1 hour every day"

6. Create **Missions**
   - "Complete React fundamentals"

7. Earn **XP**

8. Unlock **Achievements**

9. Analyze progress through **Analytics**

10. See the complete progress inside **Life Journey**

This creates a continuous personal-development loop.

# 🛠️ Technology Stack

LifeForge RPG is built using a modern full-stack web technology stack.

| Technology | Purpose |
|---|---|
| **Next.js 16** | Main web application framework, routing, Server Components, SSR, SSG and production rendering |
| **React** | Building interactive user interfaces and reusable components |
| **TypeScript** | Type-safe development and better code reliability |
| **Tailwind CSS** | Responsive UI styling and design system |
| **shadcn/ui** | Reusable and accessible UI components |
| **Prisma ORM** | Type-safe database access, queries, relationships and migrations |
| **PostgreSQL** | Main relational database |
| **Neon** | Cloud-hosted PostgreSQL database for production |
| **Zod** | Server-side and client-side data validation |
| **Passport.js** | Authentication strategy and Google OAuth integration |
| **Google OAuth 2.0** | Secure Google account login |
| **JWT (JSON Web Token)** | Authentication/session identity |
| **HTTP-Only Cookies** | Secure storage of authentication/session information |
| **Cloudinary** | Cloud storage, optimization and delivery of user-uploaded media |
| **Git** | Version control |
| **GitHub** | Source code hosting and repository management |
| **GitHub Copilot** | AI-assisted development and code generation |
| **Vercel** | Production hosting and automatic deployment |
| **Node.js** | JavaScript/TypeScript runtime and development environment |
| **npm** | Package and dependency management |
| **ESLint** | Code quality and linting |
| **Turbopack** | Fast development/build tooling used with Next.js |
